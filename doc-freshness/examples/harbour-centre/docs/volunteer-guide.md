# Volunteer guide

Thank you for giving your time. Sign in at reception on every shift, wear the green lanyard, and ask the duty manager if you are unsure about anything.

- Shift length: up to four hours
- Minimum age: 16, with a guardian's consent form
- Training: one induction session before the first shift
